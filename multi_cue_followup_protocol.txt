오목 및 5,000개 확장은 보류한다. 기존 조정·파일럿 자료는 보존한다.
기존 업데이트 식, 입력/출력 구조, AdamW 기본 weight_decay=0.01을 유지한다.
동일 형태의 여러 초기화는 별도 배치 축으로 동시에 계산한다. 각 실행의 손실은
자기 128개 예제의 평균이며, 기울기 제한 1.0도 실행별 적용한다. 단일 모델과의
출력/기울기/한 업데이트 동등성을 작은 수치 오차 범위에서 검증한다.
새 데이터 생성기는 고정 단서 수에서 벡터화한다. 기존과 동일한 분포이며 RNG의
구체적인 순서는 다르다. 모든 모델은 동일 시드·업데이트의 동일 배치를 본다.
검증 및 시험은 기존 make_batch로 생성해 파일럿과 평가 방식의 연결을 유지한다.
새 결과에는 생성기 버전, 누설 계수, 그래프 번호, 파라미터 수와 가중치를 저장한다.
FP32 계산, CUDA TF32 끔. 결과는 마지막 업데이트 모델 기준이다.

1. 기준 조건 재현

500회마다 독립 고정 검증 1,024개, 최종 시험 4,096개.
실제 Fly/RNN/GRU/누설 기억 각 3회, 재배선 그래프 0~4 각각 동일 초기화 3회:
총 27회. 실제 Fly와 각 초기화의 재배선 5그래프 평균을 짝으로 비교한다.
학습률: RNN 0.0003, GRU 0.01, Fly/재배선/누설 기억 0.003.
Fly의 0.003은 검증 점수 동점 선택이 아닌 기존 긴 예산과 연결하는 공통 고정값이다.
재배선은 별도 최적 학습률을 조정했다고 주장하지 않는다.
전체 및 질문 대상 단서의 순서별 정확도, 90%/99% 검증 최초 도달 업데이트,
질문 단서 종류 변경 및 비질문 단서 종류 변경의 대응 평가를 기록한다.
12,000회 및 16,000회 가중치를 보존한다.

2. 원인 진단
같은 초기화 1101~1103의 실제 Fly 학습 간선, 0 고정(누설 기억), 초기값 고정
간선을 비교한다. 앞 두 조건은 1단계 결과를 재사용하며 초기값 고정만 16,000회
추가 학습한다. 고정 간선 조건도 나머지 입력/출력 초기값·학습 배치·예산은 같다.
학습을 바꾸는 개선 실험은 추가하지 않고 진단으로 한정한다.
실제 Fly/고정 간선/누설 기억/RNN/GRU의 단서 종료·지연 종료·질문 후 상태에서
각 색의 물체 종류를 독립 선형 및 128은닉 MLP 판독기로 예측한다. 판독기 학습
4,096개, 검증 1,024개, 시험 4,096개, 원래 모델 데이터와 생성 시드 분리.
각 판독기는 500 업데이트, 배치256, lr=0.003, 검증 손실 최소 상태를 선택한다.
정답 대상 색뿐 아니라 제시된 모든 색을 마스킹해서 평가한다. 선형 실패는 정보
부재 증거가 아니며 MLP 성공도 원래 정책이 그 정보를 사용한다는 증거는 아니다.

3b. 방·복도 관측

실제 관측을 사용하는 모든 모델을 동일한 새 데이터/예산으로 비교한다.

탐색적 진단 부기: 1단계 중간 결과를 본 뒤, 단서는 고정하고 질문 색만 다른 단서로
바꾼 대응 평가를 2단계에 추가했다. 두 질문 모두 정답인 비율과 물체 종류가 다른
경우 답이 바뀌는 비율을 보고한다. 사전 고정한 주 평가와 구분하며 학습이나 설정
선택에는 사용하지 않는다.

탐색적 기준선 부기: 물체 종류의 최빈값만 답하는 기준선과, 모델 답이 단서 종류의
최빈값 집합에 속하는 비율을 부하 조건에 추가 기록한다. 질문 색과 단서를 연결하지

계산 실행 부기: 3a 실행 중 연산 실행 속도 개선을 위해 동일한 CUDA 순전파/역전파
