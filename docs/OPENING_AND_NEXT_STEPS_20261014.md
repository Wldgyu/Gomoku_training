# 첫 수 점검과 다음 진행 방향 (2026-10-14)

## 확인한 문제

대표 Fly(`long_plan_f_20261009/structure_compare/fly_seed4810.pt`)를 빈 12×12 판에서 직접 실행하면 흑의 첫 수로 **1행 1열**을 선택한다. 모서리는 가로·세로·대각선 세 방향으로만 확장할 수 있어 중앙보다 공격 연결과 공간 활용이 제한된다. 상대가 중앙에 두면 모서리 돌을 중앙의 공격·방어에 연결하기 어려워 흑의 선공 이점을 낭비할 수 있다. 이는 초반 공간 가치 학습의 문제이며, 첫 수만으로 필패 또는 전체 패배 원인을 입증한 것은 아니다.

현재 `env.py`의 `force_black_center`는 빈 판에서 흑의 첫 수를 **6행 6열**로 바꾼다(이 문서 좌표는 1부터 시작). 직접 실행해 원래 선택 1행 1열 → 환경 착수 6행 6열을 확인했다. 중앙 착수는 코드의 교정이며, Fly 자체가 중앙 시작을 학습했다는 뜻은 아니다. 기존 평가가 이 변경 전후 어느 조건에서 수행됐는지는 별도 확인이 필요하다. 네 모델 직접 대결은 흑백 두 돌을 미리 놓은 출발 판을 사용하므로 빈 판 첫 수 문제를 직접 평가하지 않는다.

## 다음 진행 방향

1. Fly·GRU·RNN·재배열 Fly 네 원본 체크포인트를 유지하고, 첫 수 조건을 동일하게 고정한다. 중앙 강제 적용 여부와 실제 착수·학습 기록의 일치도 확인한다.
2. 중앙 시작 뒤 초반 공격 연결, 상대 위협 방어, 방어하면서 공격하는 수를 학습 자료에 포함한다. 강한 상대가 제공하는 추천 수·평가값을 연결할 수 있는지도 검토한다.
3. 학습에 쓰지 않은 새 판에서 흑백별 승률·방어 누락·공격 연결을 평가한다. 중앙 강제 전후 비교는 같은 가중치·상대·난수 조건으로 수행한다. 추가 학습본은 기존 모델보다 개선됐을 때만 교체한다.

## REA 참고

[REA(Reverse Engineer Anything)](https://github.com/morluto/rea)는 실행 파일과 앱 동작을 분석하는 도구다. 향후 선택한 오목 AI의 입출력이나 모델 로딩 방식이 불명확하면 활용을 검토한다. 공개 소스나 분석 인터페이스가 있으면 직접 연결할 수 있으므로 REA는 현재 필수 단계가 아니다. 대상 AI는 아직 선정하지 않았으며, REA 분석 능력 부족 때문에 보류한다는 의미는 아니다. 학습의 핵심은 교사의 좋은 수·평가값을 수집해 기존 모델에 학습시키는 것이며, 다른 구조의 가중치를 바로 이식하거나 동일 실력을 보장하는 작업은 아니다.

이번 기록에서는 추가 학습이나 새 경기 평가를 수행하지 않았다. 위 순서는 향후 진행 방향이다.
