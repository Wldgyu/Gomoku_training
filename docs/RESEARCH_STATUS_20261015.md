# 오목 학습 성과 종합 보고서 — 2026-10-15

## 결론

**이번에는 전술 정답률뿐 아니라 규칙 상대 대국과 직접 대결에서도 실력 향상이 확인됐다.** 짧은 추가 학습에 머물던 단계에서 벗어나, 넓은 공간 인코더·수천~수만 회의 지도학습·충분한 공격/방어 자료·Rapfi 초중반 표적을 결합한 것이 주요 변화다. 다만 학습량만 바꾼 실험이 아니므로, 개선 원인을 학습량 하나로 확정하지 않는다.

12×12 자유 오목 네 모델의 개선과, 이후 15×15 렌주 Fly·RNN 학습을 별개 실험으로 정리한다. 판 크기·금수·뉴런 수·인코더·자료가 달라 두 실험의 승률을 그대로 빼서 개선폭으로 주장하지 않는다. 새로 학습하거나 평가 경기를 추가 실행한 보고서가 아니라, 저장된 결과와 코드를 감사해 작성한 스냅샷이다.

## 2. 12×12: 방어 안정화 후 초중반 공격 개선

평가 상대는 직접 만든 `tactical` 규칙 AI다. 환경 시드321000481·322000481, 빈 판과 다양한 개막 각각256국으로, 표의 합계는 모델당512국이다. 학습 시드5101을 기준으로 비교했다.

| 모델 | 원본 승/패/무 | 넓은 트렁크·공격/방어8000회 | +Rapfi 초중반·10000회 | 마지막 승률 |
|---|---|---|---|---:|
| Fly | 1/511/0 | 29/130/353 | **245/92/175** | 47.85% |
| GRU | 1/511/0 | 36/69/407 | **191/131/190** | 37.30% |
| RNN | 29/483/0 | 22/71/419 | **219/91/202** | 42.77% |
| 재배열 Fly | 5/507/0 | 18/48/446 | **227/122/163** | 44.34% |

전반적인 패배 감소와 공격 승리 증가가 확인됐다. 다만 **공격 자료 추가 전후의 패배는 GRU69→131, RNN71→91, 재배열 Fly48→122로 늘었고, Fly만130→92로 줄었다.** 따라서 “방어 손상 없이 전부 개선”이라고 쓰지 않는다. 즉시 막기 정확도는 높게 유지됐지만, 공격적으로 바뀐 정책의 경기 분포와 쌍위협 예방 성능도 함께 봐야 한다.

넓은 트렁크8000회는 각 종류에 학습 시드5101·5102·5103 기록이 있다. 반면 `+quiet`는5101 한 시드만 있어 그 자체의 재현 변동 폭은 아직 없다. 자료6000개 추가와 업데이트8000→10000 변경도 동시에 일어났으므로, “추가 학습량”과 “새 초중반 교사 자료”의 효과가 분리되지는 않았다.

## 3. 15×15 렌주: 새 모델과 새 교사

흑 장목·삼삼·사사 금수를 다루는 별도 규칙·환경·교사를 구현했다. 흑 첫 수는 중앙(1부터 세면8행8열)이다. 학습은 고정 예산의 지도학습이며, 기보에서 앞선 자기 차례의 순환 상태를 역전파 없이 복원한 뒤 현재 정답 수를 학습한다. D4 증강과 범주 균형 샘플링을 사용했다. 이 v1은 PPO 자기대국 학습 결과가 아니다.

- **Fly2950:** MaleCNS의 CX 내부 후보2950개 전체에서 필터링한 부분 그래프, 방향 연결207827개. 실제 연결 배치 위의 학습 가능한 인공 순환망이며 초파리 전체 뇌의 생리적 복제는 아니다.
- **RNN3000:** 은닉3000의 일반 RNN. 두 모델은 같은 공간 트렁크를 쓰지만 파라미터 수가 같지 않다.
- 전술 학습36000판(6범주 각6000), 시험3600판(각600).
- Rapfi 렌주 NNUE+200ms 탐색 추천: 학습6000판·시험400판. 합법 마스크와의 불일치로 제외된 추천은 저장 메타데이터상0건이다. 추천은 제한 시간의 제안이며 모든 합법 수에 대한 최선/강제 승리 증명이 아니다.

### 실제 대국 평가

동일 환경 시드321000481, 규칙 상대 `tactical`, 모델별256국(흑128·백128)이다. 평가는 합법 수 마스크를 적용한 고정 신경망 argmax이며, 착수 시 Rapfi 탐색이나 교사 힌트를 사용하지 않는다.

| 모델 | 승 / 패 / 무 | 승률 | 흑 승 /128 | 백 승 /128 | 실전 막기 정확도 |

## 4. 자료·코드 검증과 재현 범위

이번 정리에서 저장 배열의 정규화 키를 직접 대조했다. 12×12의 방어·공격·초중반 학습 자료는 합성·방문·공격·초중반 시험과 모두 키 중복0개였다. 15×15 전술/초중반/사람 교정 학습 자료도 전술·초중반 시험과 각각 키 중복0개였다. 이는 저장된 D4 정규 키 기준의 판 중복 검사이며, 기보 전체·모든 접두 판의 완전한 독립성을 새로 증명한 검사는 아니다.

렌주 규칙·교사·환경·데이터·대국, 12×12 방어 진단, 외부 엔진 연결의 관련 테스트는 **원 작업 폴더35개·GitHub용 복사본35개 모두 통과**했다. 최신 체크포인트의 설정과 그래프 해시도 읽어 학습 완료12000회·규칙·모델 크기를 대조했다. [감사 스냅샷](RESULTS_AUDIT_20261015.json)

업로드 사본에는 코드, 이 보고서, 원시 평가 JSON, 작은 전술/초중반 학습·시험 배열,2950 그래프를 포함한다. `.pt` 가중치·가상환경·로그·외부 엔진 바이너리와 가중치는 포함하지 않는다. 따라서 보고서 검토·일부 테스트·15×15 신규 학습은 가능하지만, 저장된 모델 평가/대국과12×12 기존 체크포인트 의존 학습에는 로컬 `.pt`가 별도로 필요하다. 외부 엔진의 추가 라벨 수집도 공식 Rapfi 배포본을 따로 준비해야 한다.

15×15 신규 학습 예시(먼저 Fly, 완료 후 RNN을 순차 실행):

```powershell
python -m gomoku.renju.train --kind fly --graph-neurons 2950 --name fly2950_reproduce --updates 12000 --extra quiet_train --data gomoku/runs/renju15_20261015/data --out gomoku/runs/renju15_20261015/reproduction
python -m gomoku.renju.train --kind rnn --hidden 3000 --name rnn3000_reproduce --updates 12000 --extra quiet_train --data gomoku/runs/renju15_20261015/data --out gomoku/runs/renju15_20261015/reproduction
```

기존 학습은 재개/추가 실행하지 않았다. 원본12×12와 새15×15 가중치는 보존하며, 이번 작업에서는 Git 커밋·push를 하지 않는다.

## 5. 다음 판단 기준

1. 15×15 Fly·RNN과12×12 `+quiet`를 추가 학습 시드로 반복하고, 새 평가 상대·시드에서 재검증한다.
2. 사람 기보79개와 모델의 새 방문 판을 이용한 교정은 별도 실행으로 저장하고, 고정 방어 판과 실제 대국을 함께 비교한다.
3. 규칙 상대를 넘어 Rapfi와 제한 예산 대국, 더 다양한 합법 개막으로 평가 범위를 넓힌다. Rapfi 추천 일치율과 Rapfi 상대 승률을 구분한다.
4. 학습량 효과를 분리하려면 같은 구조·같은 자료·같은 시드에서 예산만 바꾼 비교가 필요하다. 현재 결과는 충분한 학습량·공간 용량·초중반 자료가 결합됐을 때 실력이 개선됐다는 근거다.
