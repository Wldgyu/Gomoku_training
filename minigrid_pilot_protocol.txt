MiniGrid Memory 파일럿 실행 조건
작성일: 2026-10-01

목적

1. 실제 MiniGrid의 부분관측 이미지로 Fly·재배선 Fly·RNN·GRU의
   학습·평가 경로를 확인한다.
2. 1,000개·2,000개에서 같은 상호작용 예산과 새 평가 에피소드로
   성공률, 보상, 학습 곡선, 시간, VRAM을 비교한다.
3. 기억 단서를 관측에서 제거하고 복도 길이를 바꿔 재평가한다.

고정 조건

- 환경: MiniGrid-MemoryS11-v0, MiniGrid 3.1.0, Gymnasium 1.3.0.
- 시작 위치: 기억할 물체가 첫 관측에 보이도록 (1, 중앙)에 고정한다.
  원래의 무작위 시작 위치와 구별해 표시하고 별도로 평가한다.
- 관측: 원래의 7×7 부분관측 image와 direction만 사용한다.
  mission 문자열은 모든 에피소드에 같은 지시이므로 제외한다.
  전역 좌표, 정답 물체, 환경 내부 상태는 모델 입력에 넣지 않는다.
- 행동: left, right, forward 세 가지 이동 행동. pickup, drop,
  toggle, done은 후보에서 제외하며 모든 모델에 같다.
- 보상: 환경의 원래 성공 보상. 에피소드 상한은 100스텝이다.
- 학습: recurrent PPO, GAE, 총 10,240 환경 상호작용,
  16환경×32스텝 rollout, 업데이트당 2 epoch,
  학습률 0.0003, 엔트로피 보너스 0.01.
- 평가: 학습과 분리된 같은 에피소드 시드 64개. 2,560스텝마다
  같은 평가 세트를 재평가하고 최종에는 새 시드 64개를 사용한다.
- 시드: 301, 302, 303. 모델·크기별 3회 반복.
- 모델: 실제 Fly, 각 뉴런의 입력·출력 차수를 보존한 재배선 Fly
  seed0, Vanilla RNN, GRU. 기준 모델의 총 학습 파라미터 수를
  실제 Fly의 수와 약 1% 이내로 맞춘다.
- RNN 은닉→은닉 행렬은 카드 게임에서 선택한 직교 초기화를 쓴다.
  Fly의 간선 가중치는 여전히 학습형이며 시냅스 수는 초기값에
  반영하지 않는다. 원본 연결 방향은 유지한다.
- 순환 상태는 에피소드 경계에서 초기화한다. PPO 학습은 연속된
  rollout에 대해 역전파한다.

기억 대조와 일반화

- 단서 제거: 출발 방의 물체만 관측 생성 시 임시로 가린다.
  환경의 정답, 목표 물체, 보상은 그대로다. 같은 새 에피소드 시드를
  사용한다. 성공률 하락이 있어야 출발 단서 사용을 뒷받침한다.
- 시작 위치 변경: 학습된 체크포인트를 원래 무작위 시작 위치에서
  재평가한다. 이는 학습 분포 밖의 조건이다.
- 복도 길이: S11 학습 체크포인트를 S7·S13의 새 에피소드에
  재학습 없이 평가한다. 성능 변화는 전이 평가이며 새로 학습한
  지연별 성능과 구분한다.

판단 범위

- 3개 시드는 탐색적 결과다. 모델의 일반적인 순위를 확정하지 않는다.
- 성공률 약 50%만으로 기억 학습을 주장하지 않는다. 분기점에
  도달한 뒤 한쪽을 고르는 정책도 그 정도에 도달할 수 있다.
- 최소 한 기준 모델이 단서 제거 전후 차이를 안정적으로 보인 뒤
  본실험의 예산과 5,000개 확장 여부를 결정한다.
