질문 A: 실제 MaleCNS 연결 상대의 효과가 여러 재배선 그래프와 학습
시드에서 반복되는가?

- 과제: 원본 게임 1단계의 색상 카드, 공백 4관측 스텝.
- 크기: 1,000개 및 2,000개 뉴런.
- 실제 그래프 1개와 방향별 입력·출력 연결 수를 보존한 재배선
  그래프 5개(그래프 시드 0~4)를 비교한다.
- 각 그래프에서 독립된 학습 시드 201~205를 사용한다.
- 실행당 307,200게임, REINFORCE, 배치 256, 1,200 업데이트,
  학습률 0.001, 엔트로피 보너스 0.01로 고정한다.
- 최종 저장 체크포인트를 동일한 새 평가 게임 4,096개/시드에
  재평가한다. 학습 중의 1,024게임 평가와 분리한다.
- 실제 그래프 평균과 재배선 그래프 5개의 평균·분포를 크기별로
  비교한다. 그래프 시드와 학습 시드의 변동을 함께 보고한다.
  두 크기에서 차이 방향이 일관되고 불확실성 범위가 0을 넘는 경우에만
  구조 효과의 재현 가능성을 인정한다. 그렇지 않으면 미확정으로 둔다.

질문 B: RNN·GRU의 낮은 성공률이 공통 학습 설정 때문인가?

- 같은 4스텝 과제와 학습 예산을 사용한다.
- RNN·GRU 각각 1,000개·2,000개 파라미터 기준별로 학습률
  0.0003, 0.001, 0.003을 비교한다. 엔트로피 보너스는 0.01로 고정한다.
- 조정 시드 101~103의 최종 새 게임 성공률 평균이 가장 높은 학습률을
  고른다. 동점이면 낮은 학습률을 고른다.
- 학습률을 고른 뒤, 조정에 쓰지 않은 시드 201~205에서 새로 학습한다.
  최종 체크포인트를 질문 A와 동일한 새 평가 게임 4,096개/시드에
  평가한다. 공통 학습률 0.001도 같은 시드로 다시 학습해 시드별
  차이를 직접 비교한다. 선택 학습률이 0.001이면 동일 체크포인트를
  두 조건에서 공유한다. 실제 Fly도 같은 학습 시드로 평가한다.
- 원래 공통 설정과 선택 설정의 차이, 실패 시드 비율, 모델 간
  최종 성능을 모두 보고한다. 학습률 하나의 탐색만으로 최적 성능을
  보장할 수 없으므로 낮은 결과는 모델 능력의 상한으로 해석하지 않는다.

공통 해석 범위:
- 그래프에 저장된 synapse_count는 이 게임 모델에서 사용하지 않는다.
- 모든 Fly 뉴런에 직접 관측을 주고 모든 뉴런 상태를 출력층에서 읽는다.
  생물학적 입출력 경로의 역할을 아직 분리하지 못한다.
- 이 결과는 한 카드 게임의 특정 지연 조건에 한정한다. MiniGrid·오목,
  5,000개 뉴런의 성능으로 일반화하지 않는다.
