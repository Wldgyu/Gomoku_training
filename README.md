# MaleCNS: 초파리 연결망과 순환망의 오목·렌주 학습

실제 Fly 연결 부분 그래프, 차수 보존 재배열 Fly, 일반 RNN, GRU를 비교하는 연구 프로젝트입니다. 카드 기억·다중 단서·MiniGrid 과제에서 시작해 9×9, 12×12 오목을 거쳐 **15×15 렌주(Fly2950·재배열 Fly·RNN3000)** 까지 확장했습니다. 오목 모델은 이전 기억 과제의 가중치를 이식하지 않고 학습했습니다.

## 최신 — 통합 연구 보고서 (2026-10-19)

**[통합 연구 보고서](docs/RESEARCH_REPORT_20261019.md)** 는 원래 계획서의 질문(RQ1~4)에 맞춰 기초 과제부터 15×15 렌주까지의 증거를 한 문서로 정리합니다.

- **구조 간 일관된 우열은 확인되지 않았습니다.** 15×15에서 같은 자료·12,000회·같은 학습률로 처음부터 학습한 실제 Fly, 재배열 Fly, RNN(각 2시드)은 학습 곡선, 리그전, 대부분의 고정 시험에서 거의 같았습니다. 약한 Rapfi 대국만 Fly(38.6%) > 재배열 Fly(35.1%) > RNN(32.8%) 순이었지만, 금수 공격·깊은 연쇄 시험에서는 순서가 반대이고 시드가 2개뿐이라 단정하지 않습니다.
- **학습 가능한 파라미터는 Fly 약 126만 개, RNN 약 1,006만 개**로 8배 차이가 났지만 성능은 비슷했습니다.
- **오목 모델의 개선은 자료·교사 확장의 결과입니다.** 깊은 강제 연쇄와 금수 활용을 교사에 추가하고 Rapfi·사람 기보로 교정한 v7에서 새 시험 정확도가 올랐고(깊은 연쇄 65.0%→79.7%, 흑 금수 방어 76.0%→83.5%) 사람 대국도 달라졌습니다. 약한 Rapfi와 리그 승률은 구분되지 않았습니다.
- 계획서의 RQ2(적은 데이터 비교)와 RQ4(입력 노이즈)는 15×15에서 하지 않았습니다.

| 모델(15×15) | 약한 Rapfi 승률 (1,440국) | 리그 점수 | 금수 공격 | 깊은 연쇄 |
|---|---:|---:|---:|---:|
| 실제 Fly 2시드 | 38.6% | .499 | .820 | .827 |
| 재배열 Fly 2시드 | 35.1% | .498 | .797 | .790 |
| RNN 2시드 | 32.8% | .492 | .837 | .838 |

## 이전 12×12 단계의 학습 방법

고수의 인간 기보를 모방하는 방식이 아니라, 모델이 직접 경기하는 PPO와 전술 교사 지도학습을 결합합니다. 경기 보상은 승리 +1, 패배 −1, 무승부 0이며 잘못 둔 수마다 별도 감점하는 방식은 아닙니다. 교사는 즉시 승리·필수 방어·복수 위협·공격 연결의 정답 착수를 제공합니다.

중간 판에서 승리까지 이어가는 커리큘럼, 실제 방문 기보의 반복 재분석, 장기 공격 준비 수집, 방어 보존을 순서대로 적용했습니다. 평가는 고정 신경망이 탐색이나 교사 힌트 없이 직접 착수합니다. 흑백 모두 5개 이상 연속이면 승리하며 렌주 금수는 없습니다.
