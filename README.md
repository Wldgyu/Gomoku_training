# MaleCNS: 초파리 연결망과 순환망의 오목·렌주 학습

실제 Fly 연결 부분 그래프, 차수 보존 재배열 Fly, 일반 RNN, GRU를 비교하는 연구 프로젝트입니다. 카드 기억·다중 단서 과제에서12×12 자유 오목으로 확장했고, 최신 실험은 **15×15 렌주 Fly2950·RNN3000**입니다. 오목 모델은 이전 기억 과제의 가중치를 이식하지 않고 학습했습니다.

**2026-10-15: 공간 인코더 확대·충분한 지도학습·Rapfi 초중반 자료를 결합한 뒤 실전 성능이 개선됐습니다. 학습량만의 효과나 Fly 구조 자체의 우월성은 아직 분리해 입증하지 않았습니다.**

## 이전 12×12 단계의 학습 방법

고수의 인간 기보를 모방하는 방식이 아니라, 모델이 직접 경기하는 PPO와 전술 교사 지도학습을 결합합니다. 경기 보상은 승리 +1, 패배 −1, 무승부 0이며 잘못 둔 수마다 별도 감점하는 방식은 아닙니다. 교사는 즉시 승리·필수 방어·복수 위협·공격 연결의 정답 착수를 제공합니다.

중간 판에서 승리까지 이어가는 커리큘럼, 실제 방문 기보의 반복 재분석, 장기 공격 준비 수집, 방어 보존을 순서대로 적용했습니다. 평가는 고정 신경망이 탐색이나 교사 힌트 없이 직접 착수합니다. 흑백 모두 5개 이상 연속이면 승리하며 렌주 금수는 없습니다.
