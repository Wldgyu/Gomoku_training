# 12×12 중간 판 커리큘럼 → 다양한 공격·균형 학습 — 2026-10-07

사용자 지정 순서대로 1단계의 학습·검증 완료 후 2단계를 실행한다.
대표 Fly·GRU, 새 학습 시드4810, 공간 구조, 기보 보조 학습을 유지한다.
모든 군은 새 초기화, 보조600×128, PPO300×32×16, 에포크2 및 에포크별 보조128.
최종 예산 체크포인트만 사용한다. 같은 예제 제시/정책 결정 예산이고 추가 기보 연산량·시간·메모리는 별도 기록한다.
기존 4700 실험의 시험은 재사용하지 않고 새 검증·시험 판과 전체 경기 난수 시드를 고정한다.

대조군 baseline: 이전 실패 기보 혼합 학습 자료, 빈 판에서만 시작.
1단계 step1: 같은 보조 자료, 새 경기50%는 빈 판,50%는 강제 승리 중간 판.
업데이트1~100은 자기 착수1번,101~200은2번,201~300은3번에 이길 수 있는 중간 판을 시작한다.
즉시 승리→안전한 복수 승리 칸 생성→유일 방어를 강제한 뒤 복수 위협 생성의 최소 인증 깊이를 쓴다.
단계는 5ply까지의 해당 강제 전술이며 일반적인 모든3수 계획을 해결하지 않는다.
승리까지1/2/3은 상대 응수까지 포함한 자기 착수 수이고, 모델의 수는 교사로 교체하지 않는다.
상대는 기존30→60→85% 규칙 커리큘럼, 고정 평가는100% 규칙 상대다.
중간 판 이전 기보를 현재 가중치로 detached burn-in하고 수집/PPO 양쪽의 모든 재시작에 적용한다.
중간 판과 빈 판 경기의 학습 승률을 따로 집계한다. 혼합 전체 승률을 빈 판 승률로 해석하지 않는다.

2단계 step2: 1단계가 완료되고 검증된 다음 같은 설정·새 초기화·같은 예산으로 공격 데이터를 확장한다.
열린3, 끊어진3, 여러 방향의 교차 위협, 방어와 공격을 동시에 하는 착수,
직선/끊어진/대각선/방어 겸 공격의3착수 연결을 만든다.
모든 판은 실제 흑백 교대 기보로 도달 가능하고 비종료 판이며 교사가 모든 정답을 재검증한다.
여러 구조에 회전·반사·이동·무작위 주변 돌을 적용한다. 자연 경기 전체의 다양성을 완전히 대표한다고 주장하지 않는다.
공격의 첫 수뿐 아니라 실제 규칙 상대 응수 후 후속 공격/마지막 승리 관측도 보조 예제로 추가한다.
중간 판 시작 풀을 새 공격 자료로 바꾸고, 보조 학습은 존재하는6범주를 같은 확률로 샘플링한다.
자료의 범주별 빈도와 실제 제시 횟수를 기록한다. 공격 다양화+균형 샘플링+시작 풀 변경의 결합 효과이다.

학습 전에 새 검증/시험 시작 판을 각각 자기 착수1/2/3당128개, 총384개씩 만든다. 흑백 균형.
동일 시작 판과 난수 스트림에서 각 모델의 첫 수 정답, 해당 깊이 내 승리, 경기 종료까지 승리를 따로 평가한다.
평가 중간 판의 모든 이전 차례와 정답 판은 D4(회전·반사) 정규화 해시로 학습과 분리한다.
강한 상대 빈 판 경기: 검증/시험 각각 모델별256판, 흑백 각128.
환경 난수 시드 검증210000481·시험211000481; 중간 판 상대 시드는 각각+1000000.
1단계 검증 후 설정을 바꾸지 않고 2단계를 실행한다. 시험은 두 단계가 완료된 뒤 한 번씩 평가한다.
시험은 설정·예산 선택에 쓰지 않는다. 실제 평가 경기와 학습 판 교집합도 사후 감사한다.

평가: 깊이·패턴별 첫 수 정답/깊이 내 완승/최종 승률,
빈 판 강한 상대 승률·방어 누락률·복수 위협 도달 비율·안전한 복수 위협 생성 수.
