# 12×12 순차 개선 실험 — 2026-10-07

사용자 요청 순서: 기보 포함 보조 학습 → 공간 인식 → 전술 확대 → 강한 상대·4모델 재평가.
일반룰, 전체 판 관측, 점유 칸만 행동 차단. 모든 평가에서 교사 착수나 탐색으로 모델 수를 교체하지 않는다.

## 1. 기보 포함 보조 학습

대표 모델 Fly·GRU, 검증용 학습 시드4500. 상태0/cold와 기보/history를 새로 동일 초기화한다.
기존 2026-10-06 학습 데이터 20,000판과 검증 데이터1,024판을 재사용한다.
각 실행은 보조600업데이트×128예제 후 PPO300업데이트×32환경×16결정, 2에포크마다 보조128예제.
이 비교의 예산은 두 방식 간 동일하며 이전 본실험1800/1200 예산과 다르다.
기보 방식은 정답 판 이전의 자기 차례 관측만 순서대로 입력하고 현재 가중치로 순환 상태를 다시 만든다.
앞선 기보는 no_grad burn-in, 정답 턴에서 역전파. PPO는 기존16결정 TBPTT다.
보조 정답 수와 PPO 결정 수를 맞추고 추가 기보 관측 수·시간·GPU 메모리는 따로 기록한다.
각 방식 초기·보조 완료·최종의 검증 cold/history 정확도와 새 약화·완전 규칙 상대128경기를 비교한다.
검증 세트로 단계별 변화를 점검하며 이전 시험 세트는 설정 선택에 사용하지 않는다.

## 2. 공통 공간 인식

같은 Fly·GRU, 시드4500, 같은 학습/검증 데이터, 같은600/300 예산, 기보 보조 학습을 사용한다.
기존 전역64특징→144개 출력과 공통 공간 인코더/출력을 비교한다.
새 구조는5×5·5×5·3×3 CNN, 공간 평균→64특징의 동일 순환 코어, 공유 칸별 출력이다.
순환 상태 출력으로 CNN의16채널을 제한된 FiLM(±0.1) 조절한다.
공간 구조는 전체 아키텍처 변경이며 단일 인코더의 효과나 순환 연결 구조의 우월성으로 해석하지 않는다.
같은 구조 안에서 네 모델의 전체 파라미터 수를 근사 일치시킨다. 공간 구조/전역 구조 간 총 파라미터는 다르다.

## 3. 전술 확대

공간 구조·기보 학습을 유지하고 같은600/300 예산에서 확대 학습 데이터와 비교한다.
합법 기보의 독립 생성 데이터에서4범주를 균형 수집한다:
즉시 승리, 유일 필수 방어, 한 수 후 두 칸 이상 승리 위협 생성, 상대의 그런 위협 생성 예방.
열린3은 다음 수에 열린4를 만드는 경우를 포함하며 예방 정답은 한 수 뒤 상대의 모든 이중 승리 위협을 없애는 칸이다.
이는 정해진 전술 정의이며 모든 장기 전략·일반적인 열린3의 완전한 해법을 의미하지 않는다.
자기 즉시 승리 → 필수 방어 → 강제 이중 위협 생성 → 이중 위협 예방 순으로 분류한다.
이미 상대 승리 칸이2개 이상인 막을 수 없는 판은 지도 문제에서 제외한다.
학습 각 범주5,000판, 검증 각256판, 시험 각512판. 판+차례 해시 중복을 제거한다.
확대 데이터의 검증은 대표 모델의 결과 점검에만 사용한다.

## 4. 본실험·강한 상대 재평가

설정을 시험 성적에 맞춰 바꾸지 않고 공통 공간 구조·기보·확대 전술로 네 모델을 새로 학습한다.
독립 학습 시드4601·4602·4603, 보조1800×128 후 PPO1200×32×16, 2에포크마다 보조128.
경기 상대의 규칙 착수 비율은 업데이트 구간별30%→60%→85%, 완전 규칙100%는 최종 평가 상대다.
마지막 예산 체크포인트 사용. 확대 전술 시험 각512판과 새128/256경기 상대에서 공격·방어·전체 승률 분리.
본실험은 상대별256경기(흑백128), 6쌍×3시드×64공통 시작판×흑백 교환=2304경기.
이전2026-10-06 시험도 고정 체크포인트 비교용으로 평가할 수 있지만 설정/예산 선택에 사용하지 않는다.
기본 단계 비교는 탐색적 단일 검증 시드이고 최종 모델 비교는3개 독립 학습 시드다.
보조 학습과 구조·학습 데이터·상대 커리큘럼의 전체 결합 효과는 각 대표 단계 비교와 함께 해석한다.

기보 방식만 바꾼 모델을 새로 학습한다. 원래 검증 세트와 고정 상대256판을 같은 CPU 평가 경로로 비교한다.
