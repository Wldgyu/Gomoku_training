# 12×12 실패 기보·강제 공격 연결 파일럿 — 2026-10-07

기존 강한 상대 3,072판은 이제 학습 원자료로 사용하며 최종 시험 자격을 폐기한다.
네 모델×3시드의 해당 경기 전체를 재현하고 기존 승패·승리/방어 선택 횟수 일치를 확인한다.
유일 방어 누락 패배의 마지막 자기 차례, 복수 승리 칸이 처음 나타난 자기 차례의 1·2번 전 판을 수집한다.
중복 판+차례를 제거하고 정답이 없는 판은 제외 사유와 원 기보 위치를 보존한다.

기존 4범주 우선순위를 유지하고 강제 공격 연결 생성/예방 범주를 추가한다.

상대가 중간에 즉시 이길 수 있으면 강제 승리로 인정하지 않는다.
예방은 모든 합법 칸을 조사하여 상대 즉시 승리·안전한 복수 위협·해당 강제 연결을 없애는 칸이다.

한 모티프의 일반화 제한을 보고서에 명시한다. 전체 학습 예제 수는 대조군과 동일하게 유지한다.
