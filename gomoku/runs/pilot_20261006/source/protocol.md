# 9×9 일반 오목 첫 비교 실험

고정일: 2026-10-06, 최종 평가 전. 실제 Fly·재배선 Fly·RNN·GRU를 새로 학습한다.

규칙은 9×9 빈 판에서 흑 선공, 번갈아 한 돌씩, 가로·세로·대각선 5개 이상 연속 승리다.
흑백 모두 3×3·4×4·장목 금수가 없고 시작 위치 제한도 없다. 판이 가득 차면 무승부다.
최초 파일럿은 전체 판 관측이다. 15×15 렌주와 부분관측은 후속 연구다.

모든 모델에 공통 2층 CNN(16채널), 64차원 인코딩, 순환 상태와 현재 인코딩을 읽는
128차원 출력층 및 81개 착수 logits·상태가치 출력을 사용한다. 입력은 자기 돌·상대 돌·
마지막 착수·흑 여부의 4평면이다. 행동 마스크는 빈 칸만 제공하며 전술·금수 정보를 제공하지 않는다.
Fly의 1,000뉴런 실제 방향성 그래프와 차수 보존 재배선 그래프를 재사용하지만 가중치는 새로 초기화한다.
재배선 시드는 학습 시드 % 5. RNN·GRU 은닉 크기는 전체 학습 파라미터 수를 Fly에 가깝게 맞춘다.
동일 학습 시드의 공통 CNN 초기화는 같고, 실제/재배선 Fly는 간선 위치 외 같은 초기값을 사용한다.

학습 시드 4101·4102·4103, 모델당 400 업데이트, 32개 병렬 환경, 수집 16회,
총 204,800 학습자 결정/실행, PPO 2epoch/업데이트. 공통 무작위 상대에게만 학습한다.
학습자는 흑백을 교대로 사용한다. 승리 +1, 패배 -1, 무승부 및 진행 중 0.
중간 보상·교사 착수·탐색(MCTS)·기존 기억 과제 가중치·aux 감독을 사용하지 않는다.
AdamW lr=0.0003, weight decay=0, gamma=0.99, GAE lambda=0.95, PPO clip=0.2,
entropy=0.01, value loss=0.5, gradient norm=0.5. FP32, TF32 끔.
역전파는 16개 학습자 결정으로 끊으며 상태는 같은 경기의 다음 수집 구간으로 전달한다.
경기 종료 시 순환 상태를 초기화한다. 저장된 상태에서 시작하는 recurrent PPO를 사용한다.

고정 예산의 마지막 체크포인트를 평가하고 시험 승률로 체크포인트를 선택하지 않는다.
학습하지 않은 시드의 무작위·즉시 승리/방어 및 줄 만들기 규칙 상대에게 각각 256경기/실행,
흑백 각 128경기를 평가한다. 새 초기화 모델도 같은 상대·시드로 평가한다.
규칙 상대는 학습 상대가 아닌 외부 평가 기준이다. 최종 정책은 합법 수 logits argmax이다.

맞대결은 같은 학습 시드끼리 6모델쌍×3시드. 각 시드의 무작위 2수 시작판 64개를 공통 사용하고
모델의 흑백을 바꿔 각 시작판을 2회 평가한다(128경기/모델쌍/시드, 총 2,304경기).
시작판은 모든 모델쌍에 동일하고 최종 시험 시드는 학습과 분리된다.
경기 승·무·패, 승률, (승+무×0.5)/경기수 점수, 흑백별 성적, 평균 경기 길이를 기록한다.
시드별 수치와 평균±표본표준편차를 보고하며 단일 맞대결로 전체 실력 순위를 확정하지 않는다.
동일 시드쌍 대결이므로 다른 학습 시드와 다중 재배선의 교차 리그는 별도 후속 실험이다.

파일럿 목적은 규칙·학습·대결 체계와 보상 학습 가능성 확인이다. 충분히 강한 오목 전략이나
기억 능력·실제 연결의 우위는 이 파일럿만으로 주장하지 않는다. VRAM의 PyTorch 할당·예약 피크,
학습 결정 수·경기 수·시간·그래프 해시·코드 해시를 저장한다. 환경과 법칙은 코드 테스트로 검증한다.
