# 12×12 일반 오목 방어 학습 프로토콜

2026-10-06. 9×9 원자료와 당시 코드는 `runs/pilot_20261006/source/`에 보존했다.
일반룰: 흑백 모두 5개 이상 연속이면 승리, 금수·특수 시작 규칙 없음.

## 목적과 범위

즉시 승리와 필수 방어를 학습하고 실제 경기에서 유지되는지 검사한다.
이 실험은 기억 과제 가중치를 재사용하지 않는 새 12×12 모델이다.
전체 판을 관측하므로 Fly의 기억 우월성을 직접 입증하는 과제는 아니다.

## 공통 학습

- 실제 Fly, 재배선 Fly, RNN, GRU. 공통 CNN·출력층과 총 파라미터 수를 맞춘다.
- 학습 시드 4201, 4202, 4203. 재배선은 각 시드 % 5 그래프를 사용한다.
- 합법적으로 교대 착수한 경기에서 즉시 승리·필수 방어 상황을 채집한다.
  자기 승리 수를 우선하며, 방어 예제는 자기 즉시 승리가 없고 상대 승리 칸이 정확히 하나인 경우다.
  승리 수가 여러 개이면 어느 승리 수든 정답이다. 열린 4의 양끝처럼 한 수로 못 막는 상황을
  필수 방어 정답 문제에 포함하지 않는다. 이는 학습용 교사 정보이며 평가 정책에는 제공하지 않는다.
- 학습 데이터: 각 종류 10,000판, 독립 시드 80000012, 생성 상대의 규칙 착수 확률 30%.
- 보조 학습 1,800업데이트 × 128예제, lr 0.0003. 정답 수의 총 확률을 최대화한다.
- 이후 PPO 1,200업데이트 × 32환경 × 16결정 = 614,400 학습자 결정.
  업데이트마다 2에포크, 각 에포크에 같은 보조 손실 가중치 1.0 및 128예제.
  경기 상대는 착수마다 30% 얕은 규칙 정책, 70% 무작위 정책인 약화 상대다.
  경기 보상은 승리 +1, 패배 -1, 무승부 0. 중간 보상과 착수 탐색은 없다.
- 초기화 → 보조 학습 완료 → 경기 학습 완료를 같은 시험 조건에서 평가한다.
  시험 결과로 체크포인트를 고르거나 예산을 늘리지 않고 마지막 예산 체크포인트를 쓴다.
- 보조 학습과 PPO를 함께 바꿨으므로 효과의 인과 분리는 후속 동일 예산 대조군이 필요하다.

## 실력 재평가

- 검증: 독립 시드 81000012, 각 종류 512판, 규칙 착수 확률 30%.
  코드·수렴 확인에만 사용하며 최종 시험 성적은 학습 결정에 사용하지 않는다.
- 최종 시험: 독립 시드 82000012, 각 종류 1,024판, 규칙 착수 확률 80%.
  학습·검증·시험은 판 내용+차례 해시가 겹치지 않도록 생성한다.
- 즉시 승리·필수 방어 정확도: 상태 0에서 판독하고, 합법 기보를 다시 입력한 순환 상태에서도 검사한다.
- 새 무작위·약화 규칙·완전 규칙 상대 각각 시드당 256경기, 흑백 128경기씩.
- 모델끼리 6쌍 × 3시드 × 64개 공통 무작위 시작 2수 × 흑백 교환 = 2,304경기.
  같은 학습 시드끼리 비교하며 서로 다른 시드의 리그는 후속 과제다.
- 시험은 고정 모델, 점유 칸만 차단한 logits의 argmax. 교사 수나 방어 규칙으로 행동을 덮어쓰지 않는다.
- 승률·점수율과 학습 시드별 변동, 실제 학습 GPU 최대 allocated/reserved 메모리를 함께 보고한다.
  GPU 값은 PyTorch 통계이며 드라이버·화면·다른 프로그램의 사용량을 포함하지 않는다.

## 실행

```powershell

.venv/Scripts/python.exe -m gomoku9.tactics --output gomoku9/runs/defense12_20261006/data
.venv/Scripts/python.exe -m gomoku9.train --size 12 --seeds 4201 4202 4203 --opponent weak --warmup-updates 1800 --updates 1200 --tactical-data gomoku9/runs/defense12_20261006/data/train.npz --output gomoku9/runs/defense12_20261006
.venv/Scripts/python.exe -m gomoku9.defense_evaluate --input gomoku9/runs/defense12_20261006
```
