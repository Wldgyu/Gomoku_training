# Fly 공간 상태 처리 보고서

최종 판정: **정적 처리 우위 확인 실패 — 이번 방식은 채택하지 않고 기존 기보·순환 상태 방식으로 진행한다.**

목적: 현재 판을 고정한 채 내부 갱신을 반복하면 Fly가 더 안정적으로 착수하는지 확인했다.

## 처리 방식과 공정성
- 기존 방식: 공간 CNN 특징을 받고, 이전 자기 착수의 순환 상태를 유지한다.
- 정적 방식: 매 착수 상태를 0으로 초기화하고, 같은 판 특징으로 코어를 8회 갱신한다. CNN은 판당 한 번 계산한다.
- 한 번만 갱신하면 Fly 연결망 항이 0이다. 반복 갱신에서는 연결망이 출력에 참여하는 것을 기울기 테스트로 확인했다.
- 네 모델 모두 동일 방식 두 가지를 적용했다. 모델별 같은 시작 가중치·동일 표본 순서·학습률 0.0001·100회 지도학습·배치 128을 사용했다.
- 기본/방어/공격/준비 표본 구성은 16/64/16/32이다. PPO는 실행하지 않았다. 정적 8회는 실험 전에 고정했다.
- 처리 방식에 따라 계산량은 다르다. 기존 방식은 기보 복원도 필요하다. 모델마다 이전 학습 이력이 달라 구조 자체의 우열 비교는 아니다.

## 결과
서로 다른 경기 난수 설정 2개에서 각 방식 512판. 전술 판 384개는 이번 학습에 미사용이며 D4 변환 기준 학습 표적 판 중복은 0개다.

| 모델 | 기존 방식 승/512 | 정적 8회 승/512 | 기존 방어 누락률 | 정적 방어 누락률 |
|---|---:|---:|---:|---:|
| Fly | 0 | 2 | 15.9% | 21.7% |
| 재배열 Fly | 43 | 43 | 28.3% | 28.3% |
| RNN | 2 | 2 | 13.5% | 13.7% |
| GRU | 36 | 38 | 16.9% | 18.0% |

기존 가중치에서 기보 방식과 정적 1/4/8/16회 모두 전술 판 384개의 선택 수가 같았다. 출력 값은 달라졌으며, 착수 동일성이 출력 동일성이나 내부 상태 동일성을 뜻하지 않는다.
추가 학습 뒤 두 방식의 전술 정답 수도 모델별 같았다: Fly 356, 재배열 Fly 347, RNN 344, GRU 356 / 384.

## 판단과 다음 방향
Fly는 정적 방식에서 2승을 얻었지만 방어 누락률이 악화됐다. 공간 상태를 반복 처리하는 방식이 더 좋다고 결론 내릴 근거는 부족하다.
재배열 Fly는 두 방식 모두 43승이었다. 첫 경기 묶음에서 원래 가중치는 1승, 두 추가학습 모델은 각각 21승이므로, 개선을 정적 처리만의 효과로 해석할 수 없다. 방어 누락률도 약 28%라 기존 방어 문턱은 넘지 못했다.
현재 선택이 직접 공간 CNN 경로에 많이 의존할 가능성이 있다. 이는 관측에 근거한 추정이며, 순환 코어가 불필요하다는 증명은 아니다.
다음은 순환 출력 경로의 착수 기여도를 실제 경기 판에서 확인한 뒤 처리 방식을 확대하는 순서가 적절하다. 기존 대표 모델은 보존하고 이번 모델로 교체하지 않는다.

## 저장·검증
테스트 48개 통과. 저장한 정적 모델 4개의 로딩·상태 독립성 검증 완료. 기보 표본 160개 검증 완료.
pilot.json, confirmation.json, action_sensitivity.json, summary.json에 상세 결과 저장. 모델 8개와 재개 스크립트 보존.
중단 시 run_pilot.py / confirm.py를 다시 실행하면 완료 항목을 건너뛴다. 학습은 25회마다 저장되며 그 지점부터 재개한다.
잔여 한도가 10% 이하가 되면 알리고 새 작업을 시작하지 않은 채 저장 후 마무리한다.

이 판정은 이번 가중치와 소규모 실험에 대한 채택 실패이며, 모든 정적 처리 방식이 불가능하다는 증명은 아니다.
