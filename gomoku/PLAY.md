# 내 모델과 대국

실행 중인 화면: http://127.0.0.1:8765/

GRU·Fly·RNN·재배열 Fly의 원본 체크포인트와 직접 대국한다. 모델과 내 돌을 선택하고 **새 대국**을 누른 뒤 교차점에 착수한다. 되돌리기와 JSON 기보 저장을 지원한다. 방향키와 엔터로도 둘 수 있다.

12×12 자유 오목이며 5개 이상 연속이면 승리한다. 금수는 없고 흑 첫 수는 중앙의6행6열로 고정한다. AI는 합법 수 중 신경망이 고른 수를 둔다. 교사·탐색·추가 학습은 사용하지 않으며 가중치는 바뀌지 않는다. 순환 상태는 실제 대국 기보에서 복원한다.

서버를 다시 시작하려면 작업 폴더에서 실행한다.

```powershell
.venv/Scripts/python.exe -m gomoku.play_server --port 8765
```

서버는127.0.0.1에서만 제공한다. 대국은 서버 메모리에 보관하므로 서버를 종료하면 사라진다. 필요하면 종료 전에 기보 저장을 누른다.
