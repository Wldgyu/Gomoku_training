MiniGrid 학습형 관계 모듈의 세 단계 후속 프로토콜
작성일: 2026-10-03, 최종 평가 실행 전 조건 기록

1. 기존 RNN 401 이동 정책과 시각 판독기 501, 명시적 단서 보관·비교를
   이용한 실제 환경 주행을 기록한다. 참 환경 상태는 오프라인 라벨로만
   사용한다. 분기 라벨은 갈림길 중앙에서 동쪽을 보는 순간에만 1이다.
   S7/S11/S13과 S17Random을 사용하고 갈림길 x=7/13/17은 제외한다.
   각 설정의 기본 지형 128개×네 조합을 수집한다. 검증은 별도 시드의
   각 설정 64개×네 조합이다. 갈림길 전 단서를 본 네 조합이 모두
   있는 기본 지형만 기억 학습에 사용하고 제외 수를 보고한다.
   실제 방문 프레임 전체로 시각 판독기를 lr=0.0003, 8 epoch 추가
   학습한다. 선택은 검증 단서 정확도·분기 F1·위쪽 물체 정확도 평균,
   동점이면 검증 분류 손실이다. 새 판독기를 고정하고 경로를 변환한다.

2. lr=0.0003/0.001/0.003을 초기화 시드 701/702에서 탐색한다.
   각 조건은 12 epoch, batch128, AdamW, 같은 데이터·순서·손실이다.
   비교기를 훈련 참 단서·정답으로 200회 사전 지도학습한 뒤 고정하고,
   순환 기억과 cue readout을 선택 CE + 단서 CE로 학습한다.
   체크포인트는 검증 네 조합 성공률 → 선택 정확도 → 단서 정확도 →
   낮은 검증 손실 순으로 선택한다. 학습률도 같은 평균 기준으로
   선택한다. Fly와 재배선 Fly는 둘의 평균 검증으로 공통 학습률을
   선택해 연결 배치 비교의 최적화 조건을 같게 한다. RNN·GRU는
   각각 같은 탐색 예산을 사용한다. S9/S15/S19는 이 선택에 사용하지 않는다.

3. 고정된 학습률로 새 초기화 시드 711~715에서 실제 Fly/RNN/GRU
   각 5개, 재배선 그래프 seed0~4 각각 5개를 훈련한다. 그래프의
   뉴런 ID, 입력·출력 차수, 간선 수, 중복/자기 연결, 초기 학습
   파라미터 짝 일치를 실행 전에 검사하고 해시를 저장한다.
   최종 자율 평가는 모든 구조에 동일한 이동 정책과 새 판독기를
   붙여 S9/S15/S19, 길이당 새 기본 지형 128개×4조합을 사용한다.
   학습 시드마다 실제 Fly와 재배선 5개 평균의 차이를 보고한다.
   재배선 25개 실행을 25개의 독립 실제 Fly 짝으로 취급하지 않는다.

주 평가량: 같은 기본 지형 네 조합을 모두 성공한 비율.
보조 지표: 에피소드 성공률, 갈림길 도달·개입, 조기 분기 신호,
갈림길의 단서 판독 정확도, 시드별 값과 그래프별 값.
훈련 환경 시드: 40,000,000+설정 크기×100,000부터.
검증 환경 시드: 42,000,000+설정 크기×100,000부터.
최종 환경 시드: 44,000,000+크기×100,000부터.
표준 길이 S9/S15/S19는 이전 연구에서도 관찰했으며 이번에는
독립 새 환경 시드에 대한 평가다. 오목과 5,000개 확장은 보류한다.
