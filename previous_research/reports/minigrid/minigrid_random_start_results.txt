MiniGrid Memory 무작위 시작·길이 전이 후속 연구
작성일: 2026-10-02

핵심 판단

- 원래 MemoryS11의 무작위 시작에서는 대부분 첫 관측에 단서가 없다.
  에이전트가 출발 방으로 돌아가 물체를 본 다음 갈림길로 가야 한다.
- 성공 경로를 훈련 때 제공하면 1,000개 기준 Fly·재배선 Fly·RNN·GRU가
  이 절차와 기억 선택을 학습할 수 있다. 새 에피소드에서 단서 제거는
  성공률을 낮추고 단서 교체는 성공 방향을 뒤집는다.
- 원래 성공 보상의 PPO를 10,240스텝 추가하면 일부 모델·시드에서
  이동 또는 기억 성능이 떨어진다. 조기 체크포인트 선택은 저하를
  막지만, 이 실행에서 PPO 자체의 성능 향상은 확인되지 않았다.
- S7·S11·S13을 함께 학습하면 해당 세 길이는 모두 해결되지만,
  학습에 넣지 않은 S9에서는 모델과 시드에 따라 이동 또는 마지막
  비교가 실패한다. 실제 연결의 일반적 우위는 아직 확인되지 않았다.
- 오목과 5,000개 확장은 실행하지 않았다.

1. 원래 시작 분포 확인

MiniGrid-MemoryS11-v0를 seed 0~999로 reset한 결과 시작 x는
1~8에 분포했고 방향은 모두 동쪽이었다. 출발 물체는 (1, 중앙-1)에
있으며 첫 관측에 보인 경우는 113/1,000개(11.3%)뿐이었다.
나머지 시작에서는 물체가 뒤쪽에 있어 먼저 돌아가 확인해야 한다.
이것은 이전의 (1, 중앙) 고정 시작 파일럿과 중요한 차이다.

2. 무작위 시작 전체 이동 학습

- 환경: MemoryS11-v0, 원래 무작위 시작 위치와 100스텝 상한.
  모델 입력은 7×7 부분관측 image와 direction만이다. 행동은
  left/right/forward 세 가지다. 전역 위치와 정답은 입력하지 않았다.
- 훈련 교사: 첫 관측에 단서가 없으면 뒤돌아 출발 방으로 돌아가
  물체를 본 뒤 갈림길까지 이동하고 정답 물체 쪽으로 회전한다.
  환경 내부 정답은 교사 행동 라벨을 만드는 데만 사용했다.
  평가는 교사 없이 모델이 매 스텝 행동을 자율 선택한다.
- 1,000개 뉴런 기준 네 모델, 시드 401~403. 실행당 훈련
  에피소드 2,048개, 최대 30 epoch. 학습과 별도 검증 시드에서
  최적 epoch를 선택하고 또 다른 새 128개 에피소드로 확인했다.
- 출발 체크포인트가 동일 단계는 아니다. 실제 Fly 3개는 S11
  전체 이동 지도학습 체크포인트에서, 나머지는 S11 PPO 후속
  체크포인트에서 시작했다. 따라서 이 절의 모델 간 학습 속도나
  구조 효과를 직접 비교하지 않는다.

새 128개 에피소드의 정상 성공률(시드 401/402/403):

  실제 Fly       100 / 100 / 100%
  재배선 Fly     100 / 100 / 80.5%
  RNN            100 / 100 / 100%
  GRU            100 / 100 / 100%

실제 Fly·RNN·GRU의 성공한 실행은 단서를 볼 수 있는 위치에
도달한 비율과 분기점 도달률이 100%였다. 단서를 가리면 성공률이
대체로 약 40~59%로 떨어졌고, 반대 물체로 보여주면 0%가 됐다.
재배선 Fly 403은 단서 위치 관측 가능 92.2%, 정상 성공 80.5%,
교체 후 성공 0.8%로 남았다. 원자료는
data/minigrid_random_start/random_s11_*.json 및
data/minigrid_random_start/from_full/random_s11_fly_*.json이다.

3. 원래 보상 PPO 추가 학습과 독립 재평가

위에서 얻은 12개 정책을 원래 성공 보상의 recurrent PPO로 각각
10,240 환경 스텝 더 학습했다. 학습률 0.00003, 엔트로피 보너스
0.001이며 시작 분포는 원래 무작위 시작이다. 같은 독립 새
256개 에피소드에서 정상/단서 제거/단서 교체를 평가했다.

  모델          정상 성공률(401 / 402 / 403)
  실제 Fly      100.0 / 84.4 / 100.0%
  재배선 Fly    100.0 / 87.1 / 66.4%
  RNN           100.0 / 100.0 / 100.0%
  GRU            36.7 / 83.2 / 70.7%

RNN 3시드와 성공률 100%인 Fly·재배선 Fly 실행은 단서 교체 시
성공률 0%였고, 단서 제거 시 대체로 약 42~54%였다. 실제 Fly
402는 단서를 모두 보았으나 분기점 도달률이 84.4%로 떨어졌다.
재배선 Fly 403은 단서 위치 관측 가능 91.4%, 분기점 도달률
76.6%였다. GRU 401은 단서 위치 관측 가능 94.9%였지만
분기점 도달률 55.1%, 성공률 36.7%였다. 즉 PPO 후 성능 저하는
일부 실행에서 기억뿐 아니라 단서 탐색과 이동도 포함한다.
시드별 정상/제거/교체·도달률은
data/minigrid_random_start/ppo_low_lr/heldout_ablation.json에 있다.

GRU에 학습률 0.00001, 엔트로피 보너스 0의 탐색적 대조도 했다.
독립 256개 평가의 정상 성공률은 100.0 / 84.8 / 76.2%였다.
세 시드 모두 검증 성공률 기준으로 PPO의 초기·중간·마지막
체크포인트를 고르게 하자 초기 0스텝이 선택됐다. 선택된 모델은
독립 256개 평가에서 3시드 모두 성공률 100%, 단서 교체 0%였다.
이는 체크포인트 선택으로 이미 학습한 정책을 보존할 수 있음을
보여주며 PPO의 추가 학습이 개선을 만들었다는 증거는 아니다.
원자료: data/minigrid_random_start/ppo_stable_probe/ 및
data/minigrid_random_start/ppo_selected/.

4. 복도 길이 변화

먼저 S11 무작위 시작 지도학습 체크포인트를 재학습 없이 S7과
S13에서 평가했다. 12개 실행의 정상 성공률 평균은 S7 38.7%,
S13 55.1%였다(길이마다 64개 평가 에피소드). 단서를 가려도
성능이 유지되는 실행이 많아 이 점수를 길이 일반화된 기억
성능으로 해석할 수 없다. 원자료:
data/minigrid_random_start/length_generalization.json.

다음에는 S7·S11·S13에서 크기마다 1,024개 교사 에피소드를
혼합해 학습했다. 독립 검증에서 세 학습 길이의 평균 성공률이
가장 높은 epoch를 선택했고, S9는 선택에 사용하지 않았다.
최종 새 에피소드 길이마다 128개 평가에서 12개 실행 모두
S7·S11·S13 정상 성공률 100%, 단서 교체 성공률 0%였다.

미사용 S9의 정상 성공률(401 / 402 / 403)과 평균±표본 표준편차:

  실제 Fly      76.6 / 76.6 / 87.5%     80.2±6.3%
  재배선 Fly    76.6 / 64.1 / 50.8%     63.8±12.9%
  RNN           25.8 / 60.9 / 21.9%     36.2±21.5%
  GRU           89.8 / 50.0 / 93.8%     77.9±24.2%

S9 실패의 위치가 다르다. 실제 Fly 401/402는 단서 위치를
보는 비율 100%였고 교사 경로를 주면 마지막 선택 100%였지만,
자율 정책의 분기점 도달률은 76.6%였다. RNN 401은 단서 방문과
분기점 도달률이 모두 100%였으나, 교사 경로로 분기점에 놓아도
마지막 선택 정확도가 24.2%였다. 실제 Fly 403은 S9 분기점
도달률 100%, 성공 87.5%였다. 재배선 Fly와 GRU도 시드별 편차가
컸다. 세 길이를 맞힌 것만으로 미사용 길이에서의 비교 규칙
일반화를 보장하지 않는다.

실제 Fly의 탐색 평균이 높아 보이지만, 3시드뿐이고 출발
체크포인트 단계가 모델 사이에 완전히 같지 않다. 재배선 Fly의
시드 간 변동도 크고 GRU는 한 시드에서 93.8%에 도달했다.
따라서 실제 연결 배치의 우위나 일반적인 모델 순위를 확정하지
않는다. 원자료: data/minigrid_length_curriculum/mixed_s7_11_13_*.json.

5. 다음 연구 결정

첫째, 단서 저장과 끝의 두 물체 비교를 별도 진단·보조 신호로
분리하여 S9 같은 미사용 길이에서 선택 자체가 일반화되는지
확인한다. 둘째, 실제/재배선 Fly가 같은 단계의 체크포인트와
같은 훈련 경로로 시작하도록 맞춘 5시드 이상 반복이 필요하다.
셋째, PPO는 최종 스텝만 보관하지 말고 초기·중간 체크포인트를
분리된 검증 에피소드에서 고른 뒤 새 에피소드로 평가한다.
원래 보상만으로 처음부터 성공적인 정책을 일관되게 학습시키는
문제는 아직 해결되지 않았다. 오목과 5,000개 확장은 보류한다.
