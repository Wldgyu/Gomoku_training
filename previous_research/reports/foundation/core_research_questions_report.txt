1. 현재 단계와 결론 요약

현재까지 완료한 것은 MaleCNS v1.0 연결 데이터에서 부분 그래프를 추출하고, 그래프의 원본 일치 여부와 GPU 자원 사용량, 간단한 기억 진단 과제의 학습 가능성을 확인한 것이다. 초기 500개·1,000개 진단 뒤 게임 파일럿 규모를 1,000개·2,000개로 고정했다. 이후 기존 '기억 반전 게임'의 1·2단계 핵심 카드 규칙을 화면 없는 게임으로 옮겨 Fly·RNN·GRU 및 재배선 Fly를 같은 보상 학습 방식으로 비교했다. 1단계의 기억 지연도 1·4·8스텝으로 늘려 조건별로 처음부터 학습했다. 추가로 4스텝의 연결 구조 효과를 새 시드와 재배선 그래프 5개로 반복하고, RNN·GRU 학습률을 분리된 조정·평가 시드에서 점검했다. RNN 실패 시드 진단 후 은닉→은닉 행렬의 직교 초기화를 새 시드로 시험했다. 현재 결과는 5,000개 확장을 뒷받침하지 않는다.

MiniGrid Memory의 첫 탐색적 파일럿은 수행했지만, 9×9 부분관측 오목과 두 게임의 본실험은 아직 수행하지 않았다. 따라서 RQ1~RQ4의 일반적인 모델 간 비교 결론은 현재 모두 미확정이다. 아래의 카드 게임과 MiniGrid 수치는 예비 파일럿으로만 해석한다.

RQ1. Fly-Connectome Network는 RNN, GRU와 비교해 작은 게임에서 어느 정도의 최종 성능을 보이는가?

현재 답변: 카드 게임 1단계·지연 1에서 Fly 실제 연결의 최종 성공률이 1,000개 99.84±0.15%, 2,000개 98.96±0.15%였다. 같은 조건의 RNN은 각각 74.06±44.51%, 74.74±43.50%, GRU는 84.77±3.73%, 79.92±2.03%였다(학습 시드 3개, 각 시드의 새로운 1,024게임 평가, 표본 표준편차). 단, RNN의 한 시드는 우연 수준에 머물고 두 시드는 거의 100%였다. 재배선 Fly도 각각 99.71±0.17%, 99.32±0.85%로 실제 연결과 거의 같았다.
2단계·지연 1에서는 1,000개 Fly 실제 / 재배선 / RNN / GRU가 각각 95.74 / 94.82 / 98.76 / 73.50%, 2,000개에서 94.56 / 94.76 / 73.21 / 74.67%였다. 이 2단계는 색상·이모지 카드의 독립 라운드이며, 브라우저 게임 전체 진행은 아니다.
해석 범위: 두 짧은 카드 규칙에서만 관찰한 예비 결과다. 실제 연결 구조의 일관된 이점은 확인되지 않았으며, 부분관측 오목에서의 모델 순위는 아직 알 수 없다. MiniGrid Memory 첫 파일럿도 대부분 성공률 0%로 모델 순위를 정할 수 없었다. 별도의 합성 이진 기억 진단에서 나온 100% 정확도를 게임 결과와 혼동하지 않는다.

RQ2. 제한된 interaction budget에서 sample efficiency 차이가 존재하는가?

현재 답변: 카드 게임에서는 실행당 307,200번의 카드 선택을 수행하고 51,200번마다 성공률을 저장했다. 1단계의 지연 1·4·8과 2단계 지연 1의 곡선은 data/game_pilot에 있으나, 시드 3개와 제한된 규칙만으로 일반적인 sample efficiency 우열을 판단하지 않는다. 기억 진단 과제의 75회·250회는 최적화 업데이트 수이며 게임 상호작용이 아니다. 카드 선택 횟수도 MiniGrid의 환경 스텝과 직접 비교할 수 없다.
추가 점검: 공통 학습률 0.001의 RNN은 독립 시드의 4스텝 성공률이 약 25%였지만, 별도 시드에서 선택한 0.0003으로 바꾸면 1,000개 79.86%, 2,000개 78.06%였다. 이후 실패 시드 203을 조사하고 직교 초기화를 적용해, 새로운 시드 206~210의 4스텝 평균 성공률은 기본 초기화 1,000개 96.04%, 2,000개 67.22%에서 각각 100.00%, 99.97%로 올랐다. MiniGrid에서는 네 모델에 동일한 10,240 환경 스텝을 적용했으나 기억 학습이 확인되지 않았다. 같은 예산에서도 초기화가 학습 성공 여부에 큰 영향을 줬으므로 기존 공통 설정의 학습 곡선을 모델 고유의 표본 효율 순위로 해석할 수 없다.
필요한 측정: 동일 환경 상호작용 예산의 체크포인트에서 세 모델의 독립 평가 성능을 기록하고, 시드별 학습 곡선과 평균·표준편차를 비교한다. 10k 스텝으로 기준 모델이 충분히 학습되지 않으면 본실험 전에 예산을 다시 정한다.

RQ3. 과거 정보를 기억해야 하는 부분관측 환경에서 모델별 기억 성능 차이가 나타나는가?

현재 답변: 카드 게임의 첫 카드 정보를 지우면 평가 성공률이 대체로 무작위 선택 수준인 약 25%로 떨어졌다. 학습에 성공한 시드에서는 이전 카드를 활용한 것이다. 1단계를 지연별로 새로 학습하면 1,000개 실제 Fly는 1·4·8스텝에서 99.84 / 89.6 / 44.7%, 2,000개는 98.96 / 77.7 / 50.4%였다. 재배선 Fly는 각각 99.71 / 84.1 / 50.8%, 99.32 / 68.8 / 39.3%였다. 처음 3시드의 4스텝에서는 실제 Fly가 높았지만, 독립 시드 5개와 재배선 그래프 5개의 반복에서는 우위가 사라졌다. RNN의 초기 4·8스텝 점수는 대체로 우연 수준이었으나, 4스텝에서 학습률을 낮추면 대부분의 독립 시드가 학습에 성공했다. 그중 실패한 시드 203은 첫 카드 정보를 활용하지 못했다. 직교 초기화 후 새로운 5시드는 4스텝에서 두 크기 모두 약 100%였지만, 8스텝 탐색에서는 2,000개 3시드 중 1개가 실패했다. GRU는 1,000개 초기 4스텝 83.0%였지만 8스텝 23.7%였다. 이 결과는 해당 학습 예산과 하이퍼파라미터에서의 차이이며, 모델의 일반적인 기억 능력 순위를 뜻하지 않는다.
MiniGrid Memory 첫 파일럿에서는 모든 24개 실행의 최종 S11 성공률이 출발 단서를 가린 뒤에도 같았다. S11 학습 체크포인트를 S7·S13에서 재평가해도 단서 사용은 확인되지 않았다. 시작 단서는 첫 관측에 항상 보였지만 전체 이동과 마지막 선택을 함께 학습하는 10,240스텝 조건에서 이를 활용하는 정책은 얻지 못했다. 따라서 아직 MiniGrid의 기억 지연별 성능을 비교할 수 없다.
관찰: 1,000개·2,000개 Fly 그래프는 길이 16의 시퀀스 첫 시점에 제시한 이진 신호를 마지막 시점에 맞히는 합성 과제에서 각각 시드 42의 보관 평가 1,024개 예시 정확도 100%를 기록했다. 이전 500개 진단에서는 시드 42와 43이 100%였다.
독립 재검증: 저장된 시드 43의 500개 모델을 다시 불러와 새 2,048개 예시를 평가한 결과 정확도 100%였다. 정답을 알려주는 첫 신호를 제거하면 50.7%로 우연 수준에 가까웠다. 같은 모델은 32·64스텝 평가에서도 100%였지만, 이는 동일한 단순 과제에서 지연만 늘린 추가 점검이다.
2,000개 모델의 별도 재검증에서도 새 2,048개 예시 정확도 100%, 신호 제거 정확도 49.9%였다.
해석 범위: 이 결과는 정보가 과거에 한 번만 제시될 때 상태를 유지하고 학습할 수 있음을 보여준다. MiniGrid의 탐색, 부분관측 오목의 전략, RNN·GRU보다 우수한 기억 능력을 입증하지는 않는다.
필요한 측정: 먼저 같은 MiniGrid 이미지에서 복도 이동을 고정하고 마지막 좌·우 선택만 학습시키는 진단으로 기억 학습 가능성을 확인한다. 이후 전체 이동 정책이 단서를 사용하는 수준에 도달하면 Fly / RNN / GRU의 성공률을 복도 길이별로 같은 입력 인코더·학습 알고리즘·시드 조건에서 비교한다.

RQ4. 입력 noise, 새로운 맵, 새로운 상대 조건에서 robustness/generalization 차이가 나타나는가?

현재 답변: 아직 답할 수 없다.
근거: 0/10/20/30% 입력 noise·masking, 새 MiniGrid 맵, 학습하지 않은 오목 상대에 대한 세 모델의 평가가 없다. 첫 기억 신호를 완전히 제거한 대조 실험은 정답 누출을 점검한 것이며, 계획서의 noise robustness 측정이 아니다. 16스텝 학습 모델의 32·64스텝 평가도 맵·상대 변화에 대한 일반화와는 다르다.
필요한 측정: 동일 체크포인트에 동일한 관측 훼손 규칙을 적용해 noise 수준별 성능을 측정하고, 학습과 분리한 맵·상대로 평가한다.

4. 자원 및 구현에 관한 보조 결과

- GPU: NVIDIA GeForce RTX 5060 Ti, 약 16GB VRAM.
- 배치 32, 64스텝 역전파의 간단한 계산 진단에서 2,000개 그래프의 PyTorch 최대 할당 VRAM은 밀집 행렬 계산 약 0.101GiB, COO 희소 계산 약 0.345GiB였다.
