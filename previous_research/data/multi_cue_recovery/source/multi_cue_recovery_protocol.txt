다중 단서 후속 연구 II: 출력층 → 관측 분리 → 어려운 조건 반복
사전 기록: 2026-10-04. 사용자 승인: 1→2→3 순서 진행.
출력: data/multi_cue_recovery. 이전 결과/가중치를 덮어쓰지 않는다.
오목 및 5,000개 확장은 보류한다. TF32 끔, FP32, AdamW, 기울기 제한1.

1. 고정 기억의 출력층 안정화 진단
기준 단서2·지연4·방해2의 기존 16,000회 체크포인트 사용.
실제 Fly/재배선/RNN/GRU/누설 기억 × 기존시드1101~1103 =15개 기억.
재배선은 시드%5 그래프 하나씩(1/2/3); 전체5그래프 반복은 3단계에서 한다.
기억 모듈 파라미터를 변경하지 않는다. 질문 후 최종 상태를 수집한다.
새 출력층128: ReLU/LeakyReLU(0.01) × 최종 상태만/상태+질문 색 원핫 =4조건.
상태는 출력층 학습 데이터 평균/표준편차(하한1e-4)로 정규화한다.
질문 색 직접 입력은 과제 입력의 재사용이며 종류/정답/미관측 정보는 주지 않는다.
학습4096·검증1024·시험4096, 생성시드5.1b/5.2b/5.3b+기존시드.
모든 조건 같은 배치순서·선형층 초기화(동일 크기 조건), lr0.003, 500업데이트,B256.
50회마다 검증 손실 평가, 최소 검증 손실 가중치 선택.
15개 기억의 평균 검증 손실 → 검증 정확도 → 고정 후보순서로 공통 출력층을 고른다.
후보순서: relu_state, leaky_state, relu_query, leaky_query.
공통 출력층 선택 파일을 저장한 뒤 시험을 평가한다. 시험으로 후보를 고르지 않는다.
원래 출력층도 같은 새 시험4096개로 재평가한다. 색 교체/양 질문 정답/단서 순서 평가.
이 진단은 별도 감독학습으로 얻는 정보 판독 가능성이고 원래 학습의 자동 복구가 아니다.

2. 방·복도 관측 인식과 기억/답 선택 실패 분리
기존 CNN+기억 체크포인트15개(시드1101~1103)를 고정한다.
기존 학습8192개(seed61)·검증1024개(seed62)는 학습/조정에만 재사용한다.
새 시험 각2048개: 생성시드86(길이6/10),87(길이8/14),88(길이8/14+대기0.5).
관측은 물체/색/상태 코드이며 RGB 사진이 아니다. 경로는 고정 전진이다.
2a. CNN 특징의 선형 판독: 화면에 보이는 색별 종류12비트+질문 문 색4비트.
학습 화면8192/검증2048을 결정적 무작위 표본으로 뽑고 시험은 실제 길이 내 모든 화면.
특징 정규화는 학습 표본만 사용. BCE, 500업데이트,B256,lr0.003,최소 검증 BCE.
양성 F1/재현율/전체 화면16비트 일치/질문 문이 보이는 화면의 질문 색 정확도 기록.
질문 색 정확도는 문 색4개 logits의 강제 argmax이며 문 검출까지 요구하는4비트 완전 일치는 별도 지표다.
지표 정의 교정은 같은 저장 판독기·같은 시험에 재계산하며 학습/선택 조건을 바꾸지 않는다.
이는 고정 CNN 특징의 판독 진단이며 화면 인식의 모든 정보가 없다는 증거는 아니다.
2b. 기존 CNN+기억의 최종 상태에서 공통 출력층을500회 재학습해 원래 출력과 비교.
정규화/배치/손실 선택은1단계와 동일. 질문 색은 최종 부분관측 화면의 문 색에서만 얻는다.
2c. CNN 없는 정확한 관측 속성 요약 대조:
입력64 = 색별 물체종류 개수12 + 질문 문 색4 + 벽 위치48(항상 에이전트 위치인 칸 제외).
색별 물체 개수는 최대3으로 나누어 스케일 조정. 실제 화면만 사용하며 지도/정답/단서 역할을 주지 않는다.
물체 위치를 풀링하므로 원화면을 완전히 보존하는 oracle가 아니다. 실패는 정보 손실 때문일 수도 있다.
색×종류 결합을 입력에 명시하므로 CNN 인식뿐 아니라 결합 표현·학습 난도의 변경을 포함하는 대조다.
동일한64차원 기억 구조/원래ReLU 출력층. CNN 파라미터는 없으므로 기존 CNN과 총 파라미터는 다르다.
조정901/902,2048개 학습/1024검증,128업데이트,lr0.0003/0.003/0.01 =30회.
평균 검증 정확도 → 작은 검증 손실 → 작은lr. Fly/재배선은 공통lr로 선택.
최종새시드1201~1203,8192개 학습/1024검증,1280업데이트 =15회.
검증 정확도 → 작은 검증 손실로 체크포인트 선택. 새 시험86/87/88에서 평가.
직접 질문 입력/정규화 출력층 진단과 원래 출력층의 관측 요약 학습 대조는 구분한다.

3. 어려운 조건의 독립 반복과 출력층 보수
조건2개: 단서2·지연16·방해2 / 단서2·지연8·방해6.
새시드2201~2205. 실제Fly5 + 재배선그래프0~4×5 + RNN5 + GRU5 + 누설기억5 =45회/조건.
이전과 같은12,000업데이트,B128,각500회 검증1024·시험4096,새배치 생성.
학습률 실제/재배선/누설0.003,RNN0.0003,GRU0.01 유지. 마지막 체크포인트로 원래 모델 평가.
이 반복은 원래 학습 절차의 안정성과 실제 연결 배치 효과를 재검증한다.
각 완료 기억에1단계의 공통 출력층을 추가500회 학습(기억 고정).
새 판독 데이터4096/1024/4096,시드6.1b/6.2b/6.3b+새시드. 시험은 후보/예산 선택에 쓰지 않는다.
보수 전후를 같은 판독 시험으로 짝 비교하고 원래12,000회의 시험과 구분한다.
재배선5개를 각 시드 안에서 먼저 평균한 뒤5시드 평균/표준편차 및 짝 차이를 보고한다.
출력층 추가 학습500×256개의 감독 예산을 본체12,000×128예산에 숨기지 않는다.
불안정한 결과에서도 생물학적 초파리 뇌의 기억 능력이나 일반적인 모델 우위를 단정하지 않는다.

계산 방식 점검(3단계 본학습 전): 독립6개/30개 동시 계산의 시간만 비교했다.
정확도는 점검하거나 선택에 쓰지 않았다. 단위 모델 업데이트 시간이 짧은6개 그룹을 유지한다.
가상 점검 모델은 버리고 본학습 모델/데이터 난수를 각 실행 시드로 다시 초기화한다.
